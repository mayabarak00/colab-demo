# TaskNest — נתב פניות תמיכה

מחברת Colab שמסווגת פניות לצוות Billing, Tech או General. המודל קובע את הקטגוריה ו־LangGraph קורא אותה מה־state ובוחר את הצוות. לכל צוות יש תשובה קבועה.

## הרצה

1. פתחי את [Google Colab](https://colab.research.google.com/) ובחרי **File → Upload notebook**. העלי את הקובץ `support_router.ipynb`.
2. לחצי על סמל המפתח בצד שמאל. צרי Secret בשם `OPENAI_API_KEY` והפעילי **Notebook access**. הזיני את ערך המפתח שם בלבד.
3. בחרי **Runtime → Run all**. תא הבדיקות מדפיס את הקטגוריה הצפויה ואת הקטגוריה, הצוות והתשובה בפועל עבור שמונה פניות. כל פנייה שולחת קריאת API אחת.
4. השלימי את הרפלקציה בסוף המחברת לפי הפלט האמיתי. בהרצה מקומית נבדק הניתוב עם תשובות מדומות, ולכן תוצאות הסיווג של המודל יתקבלו בהרצת Colab.

התרשים המוטמע מציג את מבנה הגרף. בתא התרשים אפשר להפעיל רענון באמצעות `draw_mermaid_png()`, ששולח לשירות Mermaid את מבנה הגרף בלבד. התוכן של פניות הבדיקה נשלח ל־OpenAI בזמן הסיווג.

להגשה צרפי קישור למאגר GitHub ציבורי עם `prompt.md` והמחברת, וקישור לשיתוף המחברת ב־Colab. הקבצים נמצאים כרגע בתיקייה המקומית.
